# 04 — шаблон: добивание непокрытых строк

```text
Задача: дописать тесты только на непокрытый код. Ниже — отчёт coverage.py
(`coverage report -m`, с учётом ветвлений) после прогона существующих тестов.
Колонка Missing — номера непокрытых строк, «a->b» — непокрытый переход ветки.

{{отчёт}}

Метод:
1. Для каждого модуля из отчёта открой указанные строки и определи, какое условие
   нужно, чтобы туда попасть (какой вход, какая роль, какое состояние БД).
2. Напиши по тесту на каждую непокрытую ветку. Тест проверяет поведение этой ветки
   (код, detail, данные), а не просто вызывает её.
3. Если строка недостижима из внешнего интерфейса (защитный код), не пиши
   искусственный тест — перечисли такие строки в конце ответа с объяснением.
4. Существующие тесты не повторяй; новые файлы называй test_gen_gap_<n>_<тема>.py.

Фокус: {{фокус}}
```
