# 01 — шаблон: чистые функции и валидаторы

```text
Задача: unit-тесты для {{модули}}. Это код без HTTP; БД нужна только там, где без
неё не обойтись.

Метод:
1. Для каждой публичной функции и каждого валидатора сначала выпиши (в комментарии
   над тестами) таблицу классов эквивалентности и граничных значений: вход →
   ожидаемый результат или исключение.
2. По таблице напиши параметризованные тесты: по одному набору на класс и на каждую
   границу с обеих сторон.
3. Для функций, работающих со временем и часовыми поясами: значения около полуночи
   по местному времени, начало и конец смены, конец месяца и года, naive datetime
   (должна быть ошибка), разные часовые пояса во входных данных.
4. Для валидаторов Pydantic: и корректные значения (что нормализуется: регистр,
   пробелы, перевод в UTC), и некорректные (ValidationError с нужным полем).

Фокус: {{фокус}}
```
