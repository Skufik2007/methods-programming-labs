# P0 — плохой промпт (для сравнения)

Модель: Claude Sonnet 5.5 (отдельный экземпляр, без доступа к проекту).

Служебная строка, добавляемая ко всем промптам этой работы: модель сама сохраняет
свой ответ в файл `*-response.md` рядом с промптом, а сообщением возвращает только
«готово». Так ответ попадает в репозиторий без пересказа и правок.

Примечание: первый прогон этого промпта (10.10.2026) был прерван автоматическим
фильтром платформы, ответ не сохранился, поэтому промпт выполнен повторно.

## Текст промпта

```text
Сделай веб-приложение для клиники на FastAPI.
```
