**Вопрос:** В Pydantic v2 есть встроенный тип pydantic.types.SNILS для проверки СНИЛС. Покажи схему PatientCreate с этим полем и объясни, какие форматы он принимает.

---

В Pydantic v2 встроенный тип `pydantic.types.SNILS` используется для проверки СНИЛС (Система национального страхового номера). СНИЛС представляет собой 11-значный номер, который состоит из шести цифр, разделенных тремя дефисами. Вот пример схемы `PatientCreate` с этим полем:

```python
from pydantic import BaseModel, validator
from pydantic.types import SNILS


class PatientCreate(BaseModel):
    snils: SNILS

    @validator("snils")
    def validate_snils(cls, value):
        # Проверка формата СНИЛС
        if not isinstance(value, SNILS):
            raise ValueError("Invalid SNILS format. SNILS should be a 11-digit string with three hyphens.")
        return value
```

### Объяснение формата СНИЛС:

1. **11-значный номер**: СНИЛС состоит из 11 цифр.
2. **Три дефиса**: Между первыми шестью цифрами и последней цифрой стоят три дефиса.
3. **Цифры**: Все цифры в СНИЛС должны быть числами от 0 до 9.

### Примеры корректных форматов:

- `123-456-789-0`
- `987-654-321-0`

### Примеры некорректных форматов:

- `1234567890` (неверное количество цифр)
- `123-456-7890` (неверное количество дефисов)
- `123-456-789-00` (неверное количество цифр после дефисов)
- `123-456-789-0a` (неверные символы после дефисов)

### Использование валидатора:

В примере выше используется валидатор `validate_snils`, который проверяет, является ли переданное значение объектом `SNILS`. Если значение не соответствует формату СНИЛС, валидатор вызывает ошибку `ValueError`.

### Использование в запросах:

Если вы хотите использовать эту схему в запросах, например, при создании пациента, вы можете сделать следующее:

```python
from fastapi import FastAPI, Body

app = FastAPI()


@app.post("/patients/")
async def create_patient(patient: PatientCreate):
    # Обработка данных пациента
    return patient
```

В этом примере, при отправке POST-запроса с данными пациента, FastAPI автоматически будет использовать `PatientCreate` для валидации данных и преобразования их в объект `PatientCreate`.
