# Задание 4. Агент с состоянием (Redis)

**Требование:** агент хранит состояние в Redis (счётчики, статистика, кэш) и
восстанавливает его после перезапуска.

## Что сделано

Основной агент с состоянием — **Напоминание о приёме**
([`internal/reminder`](../agents/internal/reminder), общий диспетчер
[`internal/dispatch`](../agents/internal/dispatch)):

- запланированные напоминания хранятся в Redis: `mas:reminders:due` (zset, score — время
  отправки) и `mas:reminder:<id>` (hash с данными и `traceparent`);
- диспетчер раз в секунду забирает созревшие напоминания. Отправляет тот экземпляр, чей
  `ZREM` вернул 1, поэтому несколько экземпляров не шлют одно SMS дважды;
- счётчики `processed`, `failed`, `sent` лежат в `mas:stats:reminder`, общие и по агенту.
  После перезапуска счёт продолжается с сохранённых значений;
- повторная обработка той же записи не создаёт дублей (находка №4).

Тот же механизм использует агент обратной связи: опросы после приёма и статистика отзывов
`mas:feedback:stats` с NPS. Агент записи хранит в Redis брони: `SET NX` на слот защищает
от двойной записи между экземплярами.

Локально вместо Redis работает Garnet (Microsoft, протокол Redis), потому что Docker на
машине нет. В compose используется `redis:7-alpine` с AOF и volume.

## Проверка

- **Локально.** Запланированы 2 напоминания (`ZCARD mas:reminders:due` = 2), после чего
  агенты остановлены. Через 25 с агенты запущены снова: оба просроченных напоминания
  отправлены (`sent` 14 → 16), `processed` продолжился с 16, очередь пуста.
- **CI.** Использованы `docker compose restart reminder` и фаза e2e `after`:
  - «счётчик processed не обнулился после перезапуска»;
  - «счётчики mas:stats:reminder не уменьшились»;
  - «после перезапуска новое обращение проходит всю цепочку — completed»;
  - «счётчик processed продолжился с сохранённого значения — 44 → 45».
- **Тесты.** [`herd_test.go`](../agents/internal/booking/herd_test.go),
  [`idempotency_test.go`](../agents/internal/reminder/idempotency_test.go) и тесты
  хранилища на miniredis, см. [README](../README.md#тесты).
