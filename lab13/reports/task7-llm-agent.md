# Задание 7. Интеграция LLM-агента

**Требование:** агент на Python, использующий LLM (локально через Ollama или облачную),
выполняет интеллектуальную задачу предметной области (генерация ответа, классификация
текста).

## Что сделано

LLM-агент [`mas/llm_agent`](../mas/llm_agent) — процесс `python -m mas.llm_agent --role <роль>`.
Он работает с двумя ролями:

- **Анализ обращения** ([`roles/intake.md`](../roles/intake.md)) — классификация. Из
  свободного текста жалобы получаются симптомы, специальность из справочника, красные флаги
  и краткое резюме. Это первый шаг цепочки.
- **Ответ на отзыв** ([`roles/feedback_reply.md`](../roles/feedback_reply.md)) — генерация
  вежливого ответа пациенту на негативный отзыв, без медицинских назначений.

Модель — локальная `qwen2.5:3b` через Ollama (`/api/chat`, `format: json`,
`num_predict`, `repeat_penalty 1.1` против зацикливания маленьких моделей). Клиент
переписан на `httpx` async из клиента ИИ-ревью ЛР №12.

Системный промпт собирается из разделов файла роли (роль, правила, стиль, специализация) —
как в рекомендации преподавателя.

**Надёжность и безопасность:**
- текст пациента передаётся внутри явных разделителей, разделители во входе вырезаются,
  в промпте сказано считать его данными;
- ответ модели валидируется pydantic-схемой. Специальность принимается только из
  справочника, ответ должен быть на русском;
- красные флаги правил всегда добавляются к флагам модели. Кроме того, Go-агент триажа
  независимо ищет их в тексте: модель может добавить флаг, но не убрать;
- при любой ошибке модели (нет сервера, таймаут, невалидный JSON, не тот язык) срабатывает
  fallback на правила по ключевым словам, `source: "fallback"`, причина пишется в журнал.
  В CI по умолчанию `LLM_MODE=fallback`, а профиль compose `llm` поднимает Ollama.

## Проверка (локально, qwen2.5:3b на CPU)

| Жалоба | Результат | Источник |
|---|---|---|
| «Давно беспокоят головные боли по вечерам и головокружение…» | симптомы «головная боль», «головокружение» → невролог | llm, ~10 с |
| «Сильная боль в груди отдаёт в левую руку, тяжело дышать…» | красные флаги → триаж `emergency` → «Вызовите скорую: 103» | llm, ~2 с |
| «Появилась сыпь и сильный зуд на руках после смены порошка» | «сыпь», «зуд» → дерматолог | llm |
| «Заложен нос и болит ухо уже пять дней…» | ответ не прошёл схему → правила → ЛОР | fallback |
| «Неделю болит колено после падения…» (форма дашборда) | «колено» → травматолог | llm, 1 с |

Ответ на отзыв с оценкой 2 («ждал 40 минут, грубо»), `source: llm`: «Спасибо за обратную
связь. Мы сожалеем о том, что …». Шаг ответа на отзыв с оценкой 5 не запускается.

Тесты: [`tests/unit/test_llm_agent.py`](../tests/unit/test_llm_agent.py) (промпт,
разделители, разбор ответа, fallback, клиент Ollama на `httpx.MockTransport`) и
[`test_llm_language.py`](../tests/unit/test_llm_language.py).
