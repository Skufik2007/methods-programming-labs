# Задание 8. Веб-интерфейс для мониторинга агентов

**Требование:** веб-панель (Streamlit или FastAPI + Jinja2): статус агентов, очереди,
результаты задач, ручной запуск задач.

## Что сделано

[`mas/dashboard`](../mas/dashboard) — FastAPI + Jinja2. Работает в одном процессе с
оркестратором, который создаётся в lifespan, а не при импорте. Запуск: `python -m mas.dashboard`.

| Страница | Что показывает |
|---|---|
| **Обзор** `/` | агенты по heartbeat (роль, язык, статус «в сети / нет связи / останавливается», обработано / ошибок / в работе); очереди JetStream (ожидают, в обработке, повторные доставки); метрики оркестратора; состояние автомасштабировщика |
| **Запуски** `/runs` | таблица с фильтром по статусу, пагинация `limit` / `offset` |
| **Запуск** `/runs/{id}` | шаги цепочки (агент, попытки, длительность, выход), журнал событий запуска («кто что получил и передал»), ссылка в Jaeger |
| **Журнал** `/events` | события всех компонентов, фильтры, уведомления пациентам (`notify.patient`) |
| **Ручной запуск** `/new` | форма обращения, форма отзыва, кнопка «Нагрузка: N демо-обращений» |

JSON API для автообновления и e2e: `/api/agents`, `/api/queues`, `/api/runs`, `/api/events`,
`POST /api/cases`, `POST /api/feedback`, `POST /api/load`, `/healthz`.

Безопасность:
- CSP без `unsafe-inline` (middleware из ЛР №12);
- автообновление собственным JS без `innerHTML`;
- данные пациента экранируются;
- POST с чужого `Origin` получает 403.

## Находки при проверке

| № | Что было | Исправление |
|---|---|---|
| 6 | Форма «Новое обращение» в браузере получала 403 «чужой origin». При `Referrer-Policy: no-referrer` Chromium шлёт POST формы с `Origin: null` | `Referrer-Policy: same-origin`. Тест падал до правки, форма перепроверена в браузере |
