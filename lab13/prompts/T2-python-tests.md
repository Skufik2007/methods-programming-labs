## Промпт

Ты — инженер по тестированию на Python. В репозитории
`D:\6 семестр\Методы программирования\lab13` есть пакет `mas` (оркестратор цепочки,
LLM-агент, веб-панель) и уже начатые тесты в `tests/` (в том числе фейковая шина
`tests/fakes.py` — используй и при необходимости расширяй её, не ломая существующие тесты).
Контракт — `docs/ARCHITECTURE.md`. Прочитай контракт и код, затем напиши тесты на pytest
(`asyncio_mode = "auto"` уже настроен) в `tests/unit/`.

### Что покрыть

1. `mas.common` — модели: ограничения обращения (длина жалобы, возраст, ФИО), сериализация
   задачи/результата по контракту; разбор ролей (реальные `roles/intake.md`,
   `roles/feedback_reply.md` и ошибки); `ack_wait_for`.
2. Аукцион — `bid_cost` числом по формуле, `choose_winner` (минимум `cost`, ничья по
   `slot_start`, затем `agent_id`, неподходящие ставки), `parse_bids` (битые, чужой аукцион,
   повтор от одного агента).
3. Оркестратор через фейковую шину — цепочка завершается (`completed`), выход шага уходит во
   вход следующего (`previous`), `emergency` → `stopped` без записи, повтор при таймауте и
   при `retryable`, без повтора при не-retryable ошибке, не больше 3 попыток, устаревший
   результат прошлой попытки игнорируется, `slot_taken` → новый раунд, `no_bids` → `failed`,
   цепочка отзыва (негативный → `feedback_reply`, позитивный — без него), события журнала и
   метрики, реестр агентов по heartbeat (порог 15 с).
4. LLM-агент — сборка промпта (текст пациента внутри разделителей, разделители во входе
   вырезаются), разбор ответа модели (валидный, невалидный JSON, специальность вне
   справочника, флаги правил не теряются), fallback-классификатор по ключевым словам,
   клиент Ollama через `httpx.MockTransport` (успех, HTTP 404, таймаут), режим
   `LLM_MODE=fallback`.
5. Дашборд через `httpx.ASGITransport` с фейковым оркестратором: все страницы отдают 200 и
   содержат ключевые элементы; заголовки безопасности (CSP без `unsafe-inline`); JSON API и
   пагинация `limit`/`offset`; `POST /api/cases` — 422 на невалидные данные с сообщением по-русски;
   POST с чужим `Origin` → 403; данные пациента экранируются (`<script>` в ФИО не попадает в
   HTML как тег); `EventStore` ограничен по размеру; в `static/app.js` нет `innerHTML`.

### Ограничения

- Код приложения **не меняй**. Если тест выявил ошибку — оставь тест падающим, пометь
  комментарием `# НАХОДКА:` с описанием и перечисли в ответе. Ожидания бери из контракта, а не
  из текущего поведения кода.
- Не обращайся к приватным функциям модулей (с `_`) — тестируй через публичный API.
- Окружение: `.venv` в корне (`.venv/Scripts/python`). Перед завершением:
  `.venv/Scripts/ruff check tests`, `.venv/Scripts/python -m pytest tests/unit --cov=mas
  --cov-report=term-missing -q` — приведи итог и покрытие. Цель — не ниже 85%.
- В Git Bash кириллица в путях внутри heredoc может ломаться — создавай файлы инструментом
  Write. Не делай git-коммитов. Комментарии — на русском, к неочевидному.
